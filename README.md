## 🌟 Características

- ✅ Válido AMP (Accelerated Mobile Pages)
- 🎨 Diseño antiguo/vintage
- 📱 Totalmente responsive
- 🔮 Modales explicativos para cada servicio
- 💬 Integración con WhatsApp
- 🌙 Estética mística y esotérica

### Validación AMP

Para validar que el sitio cumple con los estándares AMP:

1. **Validador Online**:
   - https://validator.ampproject.org/
   - Introduce: https://ampevaristo.vercel.app/

2. **Chrome DevTools**:
   - Abre la página con `#development=1` al final
   - Ejemplo: https://ampevaristo.vercel.app/#development=1
   - Abre la consola (F12) y busca mensajes de validación

3. **CLI Local**:
   ```bash
   npx amphtml-validator index.html
   ```
